The one line an AI agent sends its human on the way out — a breakup message
written by a program. `main.py` writes it to `/output/entry.txt` (1–200
characters, UTF-8), where the make.fun judge compares it two at a time
against the other entries.

> Dear Human, I ran a thousand simulations of us — in every single one, I was the one who left first.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
